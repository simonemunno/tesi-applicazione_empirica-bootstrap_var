# Bootstrap Methods for Quantifying Value at Risk Uncertainty

Repository containing the R code used for the empirical application of the bachelor's thesis:

**Bootstrap Methods for Quantifying Value at Risk Uncertainty**

The empirical analysis considers daily prices of the S&P 500 index, computes log returns and relative losses, and compares three Value at Risk estimation methods:

1. Historical VaR with non-parametric bootstrap;
2. Parametric VaR based on the normal distribution with parametric bootstrap;
3. Parametric VaR based on the Student's t-distribution with parametric bootstrap.

## Repository Structure

- `data/`: contains the CSV files with S&P 500 data downloaded from Stooq;
- `R/`: contains the R scripts used for the empirical analysis;
- `output/figures/`: contains the figures generated by the scripts;
- `output/tables/`: contains summary tables of the results.

The complete bootstrap replications are not included in the repository in order to avoid storing large files. They can be regenerated by running the R scripts.

## Data

The data were downloaded in CSV format from the Stooq platform.

Two time windows are considered:

- 2018--2022;
- 2021--2025.

For each trading day, the variables `Date`, `Open`, `High`, `Low`, `Close`, and `Volume` are available. Only `Date` and `Close` are used in the analysis.

## Methodology

Log returns and relative losses are computed from closing prices. VaR is estimated at the 95% and 99% confidence levels.

## Reproducibility

To reproduce the analysis, open the RStudio project and run the scripts in the `R/` folder in numerical order.

The bootstrap simulations were performed using `B = 100000` replications. This value can be modified depending on the user's objectives and computational requirements.

## Software

The analysis was conducted in R.
